## Existing solutions and differentiation

- [Danger JS](https://danger.systems/js/) can implement a large-PR warning with a
  repository-specific script. It is broader and provider-aware; Diff Budget is a
  zero-runtime-dependency local CLI with one fixed contract.
- GitHub Marketplace offers PR size labelers, line-summary actions, and
  [`anti-slop`](https://github.com/marketplace/actions/anti-slop). Teams needing
  labels, comments, reactions, or GitHub API policy should use those. Diff Budget
  requires no token/API and emits JSON plus exit codes from local Git history.
- [`Lines Changed Summary`](https://github.com/marketplace/actions/lines-changed-summary)
  supports file groups and generated-code exclusions. Diff Budget deliberately has
  no glob exclusions: every path counts, binaries need explicit opt-in, and renames
  conservatively count both endpoints.
- GitHub already displays additions, deletions, and changed files. Diff Budget adds
  a reproducible merge-base calculation and an enforceable offline result before a
  PR exists or inside any CI provider.
- Range Scope answers whether paths are allowed; it cannot detect a 5,000-line
  rewrite inside an allowed directory. Diff Budget composes with it rather than
  adding a second path policy.

## Candidate choice

| Candidate | Decision |
| --- | --- |
| Merge-base diff budget | Selected: observed matrix gap, deterministic, provider-neutral, reusable in local/CI flows |
| Dependency manifest/lock gate | Deferred: native package-manager checks exist and cross-ecosystem correctness exceeds one day |
| AI review-finding delta | Rejected today: mature reviewers track rounds; stable cross-vendor finding identity is ambiguous |
| Full CI repair agent | Rejected: provider auth, hostile logs, mutations, retry bounds and evals exceed minimal scope |
| MCP disconnect recorder | Deferred: requires multiple live clients, servers and protocol fixtures |

Diff Budget is added to the flagship repository and reuses revision validation,
fixed Git execution, package, CI and release paths. Suggested discovery additions:
`pull-request-size`, `code-review-automation`, `git-diff`; launch copy remains
prepared for manual posting only.
