## Signals and engineering pain

- GitHub's September 25 update says agentic autofix can use and store Copilot
  Memory. That expands automated change production, while publication remains
  a separate step requiring concrete artifact evidence.
  https://github.blog/changelog/2026-09-25-agentic-autofix-now-uses-copilot-memory/
- GitHub changed expired Actions-artifact visibility on September 24. Actions
  artifacts and Release assets are different resources; the update is a reminder
  not to infer what shipped from an old CI artifact listing.
  https://github.blog/changelog/2026-09-24-expired-github-actions-artifacts-no-longer-shown-in-ui-and-api/
- GitHub's Release Asset REST schema exposes `digest`, `size`, `state`, and
  `name`. Those fields make an exact, locally testable comparison possible.
  https://docs.github.com/en/rest/releases/assets
- A September 21 DevOps discussion described release-note claims drifting from
  actual Git tags. It is one person's experience, not a quantified trend; it
  points to a related but distinct release-evidence need.
  https://www.reddit.com/r/devops/comments/1wm4w4w/weekly_self_promotion_thread/
- Trending showed many general agent projects, but no discovery signal changed
  the selection. Snapshot: https://github.com/trending
