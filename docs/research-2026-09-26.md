# Research log — 2026-09-26

Window: September 19–26, 2026. Searched Claude Code, AI agents, MCP, code
review, testing, CI repair, GitHub Actions, Trending, and developer discussions.
Search signals suggest a problem; they do not establish adoption or safety.

## Evidence and candidate directions

- GitHub expanded ways to request and configure Copilot code review on
  September 23. More review automation makes the distinction between an
  advisory check and a required merge check important.
  https://github.blog/changelog/2026-09-23-copilot-code-review-more-ways-to-request-and-configure-reviews/
- GitHub retired Node 20 from Actions on September 23; CI maintenance remains
  a viable alternate direction, but a generic migration checker would duplicate
  GitHub's platform validation.
  https://github.blog/changelog/2026-09-23-node-20-is-no-longer-available-in-github-actions/
- A September 23 developer discussion describes coding agents producing PRs
  faster than review can keep up. It is anecdotal and low-engagement, not a
  measured market claim.
  https://www.reddit.com/r/indiehackers/comments/1wo2ilu/are_coding_agents_creating_a_review_wall_or_am_i/
- GitHub's docs state that required checks must pass before merging a protected
  branch, and document the branch-protection REST response. They also warn that
  rulesets and bypass settings affect the actual enforcement picture.
  https://docs.github.com/en/pull-requests/reference/status-checks
  https://docs.github.com/en/rest/branches/branch-protection
  https://docs.github.com/en/repositories/configuring-branches-and-merges-in-your-repository/managing-protected-branches/about-protected-branches
- GitHub Trending and the existing toolkit were checked. A new agent catalog or
  generic AI reviewer would be redundant with existing projects. Snapshot:
  https://github.com/trending

| Candidate | Existing coverage | Difference and oracle | Decision |
| --- | --- | --- | --- |
| Required Check Audit | PR Event Gate checks a PR but only recommends making its job required | Read branch protection and compare exact context; offline protected/missing fixtures | Build |
| Node 20 workflow migration scanner | No matching module | GitHub already validates unsupported runner runtime; YAML parser adds dependencies | Defer |
| AI review-summary agent | No matching module | Hard to evaluate without review-quality ground truth; overlaps existing reviewers | Reject |

The chosen CLI uses the installed GitHub CLI for a read-only API call and has
offline fixtures. It reports branch-protection evidence only. GitHub rulesets,
bypass actors, and check-app provenance require separate evaluation; no claim
of universal merge protection is made.
