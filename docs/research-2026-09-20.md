## Existing solutions and differentiation

- GitHub Actions `paths`/`paths-ignore` decide whether a workflow runs. They are
  glob based, event dependent and subject to documented platform limits. Range
  Scope runs inside an already-started job and returns a per-path JSON decision.
- [`tj-actions/changed-files`](https://github.com/tj-actions/changed-files) and
  similar marketplace actions enumerate/filter changed files across many events.
  They are broader integrations. Range Scope is a stdlib CLI with literal paths,
  fixed local Git commands and no GitHub token/API.
- [`agent-scope-guard`](https://github.com/manuelsampedro1/agent-scope-guard)
  already validates supplied diffs with path/glob rules. Scope gating is not new.
  Range Scope resolves two commits itself, uses the merge base, NUL Git records
  and the same contract as this toolkit's local-index gate.
- [`agent-spec`](https://github.com/ZhangHanDong/agent-spec) includes broader
  staged/worktree specification guards. Teams needing BDD/spec orchestration
  should evaluate it; this module only answers one PR-path question.
- Staged Scope remains the pre-commit companion. Range Scope fills its documented
  PR commit-range gap and reuses validation/reporting instead of creating a repo.

## Candidate choice

| Candidate | Decision |
| --- | --- |
| PR/branch range scope gate | Selected: observed matrix gap, deterministic, one-day scope, real CI use |
| AGENTS.md/CLAUDE.md parity checker | Rejected: overlaps existing Agents Scope and policy semantics are ambiguous |
| Full CI failure repair agent | Rejected today: provider auth, log trust boundaries and evals exceed small scope |
| MCP disconnect recorder | Deferred: multi-client protocol fixtures and live servers required |
| Generic changed-files action | Rejected: mature alternatives; keep literal PR gate narrow |

The main repository remains the stable install and contribution entry point.
No new repository was created. Suggested discovery additions: `pull-requests`,
`continuous-integration`; prepared bilingual copy remains manual-only.
